The first Python code "hand_control" uses the computer's camera and the MediaPipe and OpenCV libraries to recognize hand gestures, and then sends the appropriate HTTP requests (forward, left, right) to ESP32 to control the robot's movement. The second code is written for ESP32,  it connects to Wi-Fi, starts a web server and, receiving commands from a Python script or from a web page, controls the direction and speed of the motors using a driver L298N.
